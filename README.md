# Elad Orbach

Independent R&D focused on **embedded systems, electro-optics, imaging, system integration, reverse engineering, and rapid prototyping**.

I build and document working hardware: custom camera systems, measurement tools, embedded interfaces, optical experiments, repairs, and control systems.

## Featured open-source projects

### [Life Fitness / ICG IC6 I²C Interface](https://github.com/eladorbach/ic6-i2c-interface)

A practical hardware and protocol reference for interfacing the **Life Fitness / ICG IC6 indoor bike** with Arduino, ESP32, Raspberry Pi, Jetson, and other custom controllers. Includes DB9 wiring, I²C packets, cadence and brake-position reads, checksums, and example code.

### [DIY Electronics & Imaging Project Code](https://github.com/eladorbach/diy-projects-code)

Code and technical notes from selected hardware projects, including **Raspberry Pi multispectral imaging**, multi-camera multiplexing, and **Arduino Sony VISCA camera control**.
