# Eight-month literature and implementation survey — AGX multimodal 3D
**Review window:** 2026-02-22 through 2026-10-22 (inclusive; current as of 2026-10-22).
**Scope:** M1600 + monochrome IMX252 + IMX250 PolarSens, eventual QT128/Waymo/conditional Innoviz.
**Use:** architecture selection and reproducible experiments; **nothing below has been installed, trained or benchmarked on our AGX by virtue of appearing here.**
**Method:** prioritize dated primary papers, author repositories and recent code updates; distinguish paper claims from verified Xavier compatibility.

## Decision in one paragraph
Do **not** install a new entire Gaussian-SLAM stack or a second ROS runtime now. Verify raw Velarray geometry and M1600/IMX252 synchronization, measure flat walls/edges and a held-out truth dataset, build simple probabilistic multi-view registration/geometry maps, then compare 2026 algorithms offline on immutable trials. Add IMX250 PolarSens to reflection/mirror ablations. Gaussian renderers create compelling displays only after calibrated metric geometry. Our measurable novelty is *trustworthy smooth surfaces with uncertainties and transparent rejected/filled regions*, not merely high point count or photographic smoothness.

**Key limitations of research transfer:** Different LiDAR angular samplers, rolling/solid-state scan patterns, reflectivity distributions, camera spectral bands, synchronization and CUDA resources. Published FPS and accuracy are *not* measurements on AGX Xavier.

## Recent OpenAI / Anthropic / Meta research and HOW to combine tools
These are **design references and possible engineering assistants**, not sensor fusion algorithms and NOT live models verified to run locally. No paid/API calls assumed.

- **OpenAI, September 2026:** GPT-6 Astra presents tool-assisted CAD, computer use and engineering workflows. Vendor-published BenchCAD score is not independent evidence that it can calibrate LiDAR; use an OpenAI-type coding/research reviewer for reproducible scripting, provenance and benchmarking, never as physical ground truth.
  https://openai.com/index/gpt-6-astra/
- **OpenAI, September 8, 2026:** GPT-5.6 Sol quantum-lab case illustrates AI controlling bounded lab measurements then checking outputs; adapt that pattern to *read-only, time-limited camera/LiDAR acquisition and regression testing*.
  https://openai.com/index/codex-quantum-computing-experiments/
- **Anthropic, July 9, 2026:** 'Claude plays robotics' reports that frontier models work better with bounded high-level policies than with low-level torque commands and still struggle with persistent spatial state. Use a Claude-type second critic for designs and failure analysis, not as an unsupervised realtime trajectory controller.
  https://www.anthropic.com/research/claude-plays-robotics
- **Meta, June 2, 2026:** SA-3DAO benchmark provides grounded evaluation examples of image-to-3D reconstruction. This release is in our window although its underlying SAM3D work was published in 2025. Meta/SAM-derived segmentation might mask foreground/moving objects **if licensed, available, small enough and benchmarked**; it cannot certify LiDAR geometry or replace calibration.
  https://ai.meta.com/datasets/sa-3dao-sam-3d-artist-objects/
- **NVIDIA, CVPR 2026:** SAGE agentic 3D scene generation uses critics/iterative checks for simulation-ready scenes. Borrow idea of independent quality gates; do not confuse simulated scenes with real sensor observations.
  https://research.nvidia.com/labs/cosmos-lab/sage/

**Proposed complementarity (not currently configured):**
1. AGX deterministic sensor service: receive bounded raw measurements, hash, decode and compute metrics; trusted ground-truth provenance.
2. Coding/research agent: propose changes in branch + unit tests; no power/firmware/kernel/network changes.
3. Independent critic (Claude or different reasoning engine when user has access): attack assumptions, inspect packet schema, timestamps, calibration math, and overfitting; produces machine-checkable review.
4. Meta-class scene segmentation model when compatible: annotate images only; not permitted to rewrite metric XYZ.
5. Gatekeeper program: compare numeric results on held-out raw scenes before any changes reach live publisher or published dataset.

**No new API accounts or paid subscriptions**, no direct internet access to raw private camera frames, no unapproved server-side inference, and no autonomous remote pushes from agent branches without provenance checks. Different company model names alone don't provide ensemble accuracy; disagreements should trigger experiments.

## Chosen near-term computational architecture (Xavier-conscious)
- On AGX REALTIME: single bounded sensor ingress each, raw circular buffering under size caps, machine timestamps with explicit clock-domain metadata, low-rate display previews, validated packed PointCloud2, anti-multipath flags only (do NOT delete original returns).
- AGX NEAR-LINE: deterministic voxel downsample for fast matching, per-surface point-to-plane residual quantiles and plane normal uncertainty, view coverage, cheap scan registration and loop closure if reliable pose constraints exist.
- AGX/BATCH if resources permit: larger multiview surfel fusion, reflectance/polarization calibration, RANSAC plane clusters with conservative normal-consistency edge handling.
- Only if compatibility proven: ROS2 iG-LIO / GPU Gaussian training. Use container/snapshot, separate from ROS1 live baseline; don't deploy both permanently merely to 'collect ROS versions'.
- Compare **raw and processed on identical held-out viewpoints**. Keep triple accounting: original observed points, independently registered points, modeled/inferred surfaces.

## Critical physical risks
- IMX252 lens intrinsics and LiDAR-camera rigid transform not yet measured. Current preview brightness/exposure must be characterized first.
- Sensor host timestamp is not hardware sync. Every motion-induced alignment metric needs a measured time-offset/jitter budget.
- Moving sensor without verified pose/IMU: accumulating points directly will *blur* surfaces, not smooth them.
- Mirror returns can pass plausible intensity/range tests. Contrast across independent viewpoints + camera/PolarSens consistency; report false positives. No universal mirror classifier claimed.
- No guaranteed Gaussian splatting benefits with monocular **mono** IMX252 and an older Jetson GPU; photorealistic RGB demands actual RGB source.
